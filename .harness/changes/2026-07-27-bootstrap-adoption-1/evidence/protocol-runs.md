# 协议执行记录（可复现审阅协议的历次运行）

本文件把**协议运行的观察值落进仓库**。此前会话 C 的完整运行只在对话中披露、
从未入库——外部审阅第 10 轮把这记为 I3：**未入库的证据等于不存在**，
与「扫描表留在被 git 忽略的临时目录」是同一类错误。

记录约定：

- **历史条目**绑定其运行时的精确 HEAD，事后不修改；
- **当前条目**的约定（明确成文，避免每轮重新解释）：

  1. 条目在**提交之前**写入，因此它只记录**提交前工作树状态的事实**
     （门禁退出码、分流字节数、脚本 SHA、摘要、收敛计数等）；
  2. 它**不记录自身所在提交的 SHA 与该提交的 CI 结论**——那两项在写入时尚不存在，
     若为它们再开一个提交，就会陷入「记录自己 SHA」的无穷回归；
  3. 这两项的**验证跳转点是 PR 正文**：推送后由 PR 正文给出本记录所在提交的精确 SHA、
     `git rev-list --count` 与 CI 运行号。**PR 正文是当前条目的复核入口，不是补充说明。**

  一句话：**提交前事实入库，提交后指针入 PR 正文**。
